Готовые поля, чтобы завести 4 канала: Telegram ЦППК, MAX ЦППК, Telegram «Стрелка», MAX «Стрелка».

Тексты можно вставлять как есть. Если поле не принимает всю длину, берите короткую версию.

## Общие правила при создании

- Два голоса. ЦППК: учебное учреждение. «Стрелка»: районная сводка. Не копировать одно описание в оба канала.
- ЦППК в мессенджерах публичные. «Стрелка» тоже публичная, иначе жители не найдут канал по ссылке из VK.
- Сразу после создания: аватар, описание, публичная ссылка, закреп. Пустой канал в поиске выглядит как брошенный.
- Комментарии у ЦППК на старте лучше выключить. У «Стрелки» можно включить: жители уточняют, действует ли перекрытие.
- Запись на обучение только через сайт, не через личку канала.
- В «Стрелке» нет прайса ЦППК и набора на права.

Лимиты, на которые рассчитаны тексты:

| Поле | Telegram | MAX |
|---|---|---|
| Название | до 128 символов, на телефоне видно ~25-40 | до 200, в выдаче часто обрезается ~25 |
| Описание | 255 | 400 (часть клиентов показывает меньше, короткие версии ниже 200) |
| Юзернейм | 5-32, латиница, цифры, `_`, не с `_` | у бизнес-канала часто выдаётся автоматически (`idИНН_biz`) |
| Аватар | квадрат 800×800, смысл в центре круга | квадрат 512×512 |

## 1. Telegram: ЦППК

Тип: канал, публичный.

**Название**

```
ЦППК · Росавтодор
```

Если не влезает или выглядит чужим: `ЦППК СПб`.

**Юзернейм (пробовать по порядку)**

1. `cppkspb`
2. `cppk_spb`
3. `cppk_rosavtodor`
4. `mcppk_spb`

Ссылка будет `t.me/<имя>`. Совпадение с `vk.ru/cppkspb` полезно.

**Описание (137 символов)**

```
Официальный канал образовательного центра Росавтодора в Санкт-Петербурге. Категория B, ДОПОГ, самоходная техника, БДД. Запись: cppkspb.ru
```

**Фото**

`avatar-cppk-800.png`. Не ставить личное фото сотрудника.

**Настройки после создания**

- Подпись сообщений: включить (видно, что пишет учреждение).
- Комментарии: выключить до появления модерации.
- Пригласительные ссылки: одна постоянная публичная.
- Связанная группа обсуждения: не создавать в день запуска.

**Закреп (навигация)**

```

Учебная часть
edu@cppkspb.ru
```

## 2. MAX: ЦППК

Тип: бизнес-канал организации, не личный блог.

Как заводить: [business.max.ru](https://business.max.ru) или кабинет партнёра MAX / МСП.РФ. Нужны ИНН учреждения и подтверждение (Госуслуги, банк или ЭЦП). Ник часто нельзя выбрать: система ставит шаблон вроде `idИНН_biz`. Это нормально. Название и описание важнее ника.

**Название**

```
ЦППК · Росавтодор
```

**Описание (273 символа, в лимит 400)**

```
ФГАОУ ДПО «Межрегиональный ЦППК» им. В. К. Артюха. Образовательный центр Росавтодора в Санкт-Петербурге.
Категория B, C/D/CE, ДОПОГ, самоходная техника, БДД, программы для дорожного хозяйства.
Запись и документы: cppkspb.ru
Учебная часть: edu@cppkspb.ru, +7 (911) 928-14-78
```

Если поле короче 200 символов:

```
ЦППК им. В. К. Артюха, учебный центр Росавтодора. B, ДОПОГ, техника, БДД. Санкт-Петербург. Запись: cppkspb.ru
```

**Фото**

`avatar-cppk-512.png`. Тот же знак, что в Telegram.

**Закреп**

Тот же текст, что в Telegram. В конце MAX-закрепа добавьте строку, когда бот будет готов:

```
Справка по программам: напишите боту ЦППК (ссылку вставим после запуска бота).
```

Пока бота нет, эту строку не публиковать.

**Первый пост**

Как в Telegram, плюс одна фраза:

```
Официальный канал в MAX. Тот же центр, что vk.com/cppkspb и сайт cppkspb.ru.
```

## 3. Telegram: «Стрелка»

Тип: канал, публичный. Это не канал администрации района.

**Название**

```
Стрелка
```

Подзаголовок в описании, не в названии. Если название занято визуально в поиске: `Стрелка · Васильевский остров`.

**Юзернейм (пробовать по порядку)**

1. `strelka_vo`
2. `strelka_ostrov`
3. `vo_strelka`
4. `strelka_vasileostrov`

Не брать `strelka` без уточнения: имя слишком общее, скорее всего занято, и путается с другими «Стрелками».

**Описание (130 символов)**

```
Сводка Васильевского острова: мосты, ветер, перекрытия, афиша у воды. Не администрация района. Сообщество: vk.ru/vasilyevskyostrov
```

**Фото**

`avatar-strelka-800.png` (колонна-маяк). Не ставить логотип ЦППК.

**Настройки**

- Подпись сообщений: по желанию, лучше одним именем редакции.
- Комментарии: включить, если есть кто отвечает в первый час.
- Гео: Санкт-Петербург, если поле есть.

**Закреп**

```
«Стрелка». Васильевский остров.

Утром в будни: одна сводка.
Мосты, ветер, работы на набережных, события с адресом на острове.

Основное обсуждение и фото жителей: https://vk.com/vasilyevskyostrov
Предложить новость: сообщения сообщества во ВКонтакте.

Это не канал администрации и не учебный центр.
Прайс автошколы и набор на права здесь не публикуем.
```

**Первый пост**

```
Канал открыт.

Формат: одно утреннее сообщение в будни, ориентир 8:30.
Если сводки нет, на острове не произошло ничего, что стоит отдельного уведомления.

Лента с фото и обсуждением остаётся во ВКонтакте.
```

Если утренней сводки ещё нет, не оставляйте канал без закрепа. Первый пост выше достаточен на несколько дней.

Тип: обычный канал (с февраля 2026 его можно создать без юрлица). Не делать вторым бизнес-каналом ЦППК: иначе в поиске «Стрелка» выглядит как ещё одно официальное лицо учебного центра.

**Название**

```
Стрелка
```

**Описание (без тире, 205 символов)**

```
«Стрелка». Сводка Васильевского острова.
Мосты, ветер, перекрытия, афиша у воды. Не пресс-служба администрации.
Основное сообщество: vk.ru/vasilyevskyostrov
Предложить новость можно в сообщениях сообщества.
```

Короткая версия:

```
Сводка Васильевского острова: мосты, ветер, перекрытия, афиша у воды. vk.ru/vasilyevskyostrov
```

**Фото**

`avatar-strelka-512.png`.

**Закреп и первый пост**

Как в Telegram «Стрелка».

## Что писать в первую неделю, чтобы каналы не умерли

ЦППК (3-5 постов в неделю, не каждый день):

1. Закреп и пост «канал открыт» (уже выше).
2. Чек-лист документов на категорию B, со ссылкой на сайт.
3. Кому нужен ДОПОГ, кому нет.
4. Адреса площадок.
5. Старт ближайшей группы, если дата подтверждена учебной частью.

Слоты: вторник-пятница, 9:30 или 18:30.

«Стрелка» (одно сообщение в будни):

```
Остров, [дата]
Мосты: без ограничений / ограничение с … до …
Ветер на стрелке: … м/с
Работы: [адрес, время, если есть]
Афиша: [одно событие с адресом на острове] / сегодня без событий
Подробности и фото: пост VK
```

Не переносить в мессенджеры соседский UGC и не дублировать дословно карточки VK, кроме отмены группы или экстренного ограничения.

UTM на сайт из каналов:

```
https://cppkspb.ru/study?utm_source=telegram&utm_medium=channel&utm_campaign=b
https://cppkspb.ru/study?utm_source=max&utm_medium=channel&utm_campaign=dopog
```

`utm_campaign` меняйте по теме: `b`, `dopog`, `tech`, `bdd`.

## После создания: куда вписать ссылки

1. Шапка и закреп VK ЦППК: Telegram и MAX ЦППК.
2. Шапка VK «Стрелки»: Telegram и MAX «Стрелки».
3. Сайт cppkspb.ru, блок контактов: только каналы ЦППК.
4. Этот файл: дописать фактические `@username` и ссылки MAX, когда система их выдаст.

Порядок запуска контента по стратегии остаётся прежним: сначала ритм ЦППК, «Стрелка» в мессенджерах живёт утренней сводкой, а не набором. Создать все четыре канала в один день можно; заполнить шапки нужно сразу, чтобы они не стояли пустыми.
