## 1. ВКонтакте

Тип: публичная страница. Не закрытая группа.

**Название**

```

```

Запасное: `ЦППК · Екатеринбург`.

**Короткий адрес (пробовать по порядку)**

1. `cppk_ekb`
2. `cppkekb`
3. `cppk_ekaterinburg`

Ссылка будет `vk.com/<имя>`. Не занимать и не дублировать `cppkspb`.

**Статус (71 символ)**


**Категория:** образование / автошкола, если список требует выбрать одно.

**Сайт:** https://cppkspb.ru  
**Телефон:** +7 (343) 257-57-92  
**Адрес:** Екатеринбург, ул. 8 Марта, д. 158  
Если форма просит офис: 207, 2 этаж (данные 2ГИС, сверить).

**Кнопки меню**

1. Запись → страница программ на сайте с UTM `utm_source=vk&utm_medium=menu&utm_campaign=ekb`
