# ЦППК в Екатеринбурге

Рабочий документ: рынок филиала и готовые тексты для каналов.

Публичный адрес: [timaxlacs.github.io/cppk-ekaterinburg](https://timaxlacs.github.io/cppk-ekaterinburg/)

- [Рынок](https://timaxlacs.github.io/cppk-ekaterinburg/rynok/)
- [Каналы](https://timaxlacs.github.io/cppk-ekaterinburg/ploschadki/)
- [Оформление](https://timaxlacs.github.io/cppk-ekaterinburg/oformlenie/)

Отдельные страницы каналов: [поиск](https://timaxlacs.github.io/cppk-ekaterinburg/poisk/), [сайт](https://timaxlacs.github.io/cppk-ekaterinburg/sajt/), [карты](https://timaxlacs.github.io/cppk-ekaterinburg/karty/), [Авито](https://timaxlacs.github.io/cppk-ekaterinburg/avito/), [Директ](https://timaxlacs.github.io/cppk-ekaterinburg/direct/), [ВКонтакте](https://timaxlacs.github.io/cppk-ekaterinburg/vk/), [Telegram](https://timaxlacs.github.io/cppk-ekaterinburg/telegram/), [MAX](https://timaxlacs.github.io/cppk-ekaterinburg/max/).

Сверка фактов: 17.09.2026. Не пригородная АО «ЦППК».

## Как запустить локально

```bash
npm install
npm run dev
```

Сервер: `http://127.0.0.1:43147`.
