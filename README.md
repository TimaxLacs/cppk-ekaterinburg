# ЦППК в Екатеринбурге

Рабочий документ для разговора: обзор рынка филиала Межрегионального ЦППК и глава о картах, соцсетях, мессенджерах и сайте.

Сайт филиала в этот репозиторий не входит — его вы делаете отдельно. Здесь только постановка страниц и тона.

Это предложение, не официальная позиция учреждения. Опора: [cppkspb.ru](https://cppkspb.ru/), карточки 2ГИС, открытые городские обзоры 2025–2026.

## Главы

1. [Обзор рынка](/rynok) — с кем сравнивают филиал, цены категории B, два адреса, где цифровой след рвётся.
2. [Площадки](/ploschadki) — как оформить 2ГИС / Яндекс / Google, сообщество ВКонтакте, Telegram и MAX, что должно быть на своём сайте.

Календарного плана на 90 дней нет специально.

## Запуск локально

```bash
npm install
npm run dev
```

Адрес: http://127.0.0.1:43149

Статическая сборка (как на GitHub Pages): `npm run build`, затем `npm start`. Файлы появляются в каталоге `out/`.
